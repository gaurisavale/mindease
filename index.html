Features

Support that meets you where you are

MindEase combines a conversational companion with evidence-based Cognitive Behavioral Therapy tools, built for first-tier support, not as a replacement for professional care.

AI companion chat

LLM-powered replies grounded in CBT, with memory of the conversation and one practical next step each time.

Self-check assessments

Six short screeners, including the validated PHQ-9 and GAD-7, with clear results and tailored suggestions.

CBT toolkit

Guided breathing, grounding, thought reframing with thinking-trap detection, affirmations, and journaling.

Crisis detection

Every message is screened for signs of self-harm before anything else runs, with immediate helpline referral.

English, Hindi, Marathi

Chat in English, Hindi, Marathi or Hinglish. Crisis phrases are caught in all of them, in Devanagari too.

Private by design

No accounts and no chat logs. Messages go to the AI only to write a reply, and MindEase never stores them.

How it works

From message to response in five stages

A deterministic safety layer wrapped around a language model. Open the chat and toggle NLP pipeline to watch each stage live.

01 / INPUT

Capture

Typed text or a quick-reply chip, normalised (contractions, casing, scripts).

02 / NLP

Understand

Tokenisation, lemmatisation, lexicon sentiment with negation handling, intent scoring.

03 / SAFETY

Crisis check

Runs first, every time. A match overrides all other routes and surfaces helplines.

04 / MODEL

Generate

An LLM (Gemini Flash by default) writes the reply through a forced tool call: reply, intent, risk level and suggested actions as structured JSON.

05 / GUARD

Validate

The server whitelists actions, caps output, and attaches helplines when the model flags risk. Offline, local rules take over.

About the project

Closing the gap between needing help and asking for it

Stigma, cost, and a shortage of trained professionals leave many people, especially young people, without support. MindEase explores how a carefully designed conversational agent can offer anonymous, always-available first-tier support grounded in CBT, while staying honest about its limits and handing off to humans when it matters.

The original system was built with a Python and Django backend, NLTK and spaCy for language processing, and a web chat interface. This version upgrades the conversation layer to an LLM (Gemini Flash by default, swappable for any OpenAI-compatible provider), served from a serverless API, while keeping crisis detection as deterministic rules that run before the model, in the browser and again on the server.
